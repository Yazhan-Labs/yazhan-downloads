# Yazhan Downloads — Release Handoff

Use this when an app is ready for public release.

SOURCE REPOSITORY:
SOURCE VERSION:
SOURCE TAG:
SOURCE COMMIT:
SOURCE WORKFLOW RUN ID:
SOURCE ARTIFACT NAME:
PUBLIC RELEASE TAG:
PUBLIC RELEASE TITLE:
PRIMARY ASSET:
PRIMARY ASSET SHA-256:
OWNER RELEASE APPROVAL: YES / NO

The source artifact must contain:

- the approved public release asset(s)
- `SHA256SUMS.txt`
- `RELEASE_NOTES.md`

The source app only prepares and validates the release package.

`Yazhan-Labs/yazhan-downloads` is the only public publisher.

Do not provide or store a Downloads publishing token in source app repositories.
